# Bro-Guru Info Product — content cutter

Turn hard-won expertise into a funnel-driven info product, and cut any piece of its content fast. The genre's promise: *"I paid the learning-curve tax so you don't have to — pay a little, skip the pain, get the win."* Worn honestly, the grift's costume delivers a real lesson.

The genre's full anatomy — its parts and the seams between them — is in `concept.md`. Read it once when bootstrapping a new product; you don't need it to cut a single piece.

## The one rule that makes or breaks it

**The product PROFILE is the single source of truth; every piece of content is *derived* from it, never re-decided.** Write the profile once per product — audience, the moment they buy, the enemy, the promise, the proof, the voice, the atom list. After that a lead magnet, a sales page, a thread, and an email are all *the same atoms re-arranged for a channel*. You never re-invent the positioning per piece. When two pieces disagree on the promise or the voice, the profile was bypassed — fix the profile, not the piece. **This is the whole reason cutting content is instant: the profile is the type, the content is residue forced by it.**

## The honest-grift line (non-negotiable)

Full grift **aesthetics**, zero grift **substance**. Confident outside; true inside. The aesthetic is allowed — urgency, swagger, the enemy, blunt second-person, "I wasted two years so you won't." The lies are banned — false claims, a hollow free tier, fake countdowns/testimonials, results you can't deliver. The one move a real grifter can't afford and you must make: **the free thing actually works.** That single fact is the entire moat. Details and the pass/fail checklist live in `voice.md`.

## Workflow

1. **Ensure the profile exists.** Find the product's `PROFILE.md` (for an existing product, its vision/positioning docs count as the profile). If there's none, bootstrap one: read `profile-template.md`, infer aggressively from the subject, ask only the few fields you genuinely cannot (typically: the precise audience, their buying moment, the enemy), then write `PROFILE.md`. **Never cut content against a profile that doesn't exist — that's fiction.**
2. **Pick the cut:** which artifact (lead magnet / landing page / thread / email) and which atom(s) from the profile's atom list. If unspecified, recommend from the list — the most universal scar with the cleanest before/after leads.
3. **Load the type, then the template.** Always load `atom.md` (the substance unit) and `voice.md` (the register). Then load the one matching file from `artifacts/`. Don't load templates you aren't using.
4. **Generate into the product's own directory.** Each artifact = the chosen atom(s), arranged for the channel, ending in exactly one call-to-action.
5. **Run the gate before returning.** Walk `voice.md`'s honest-grift checklist: does every claim trace to something true in the profile? Is the free piece *whole*, not a tease? Did any banned move slip in? If any answer is wrong, it is not done — fix it, don't ship it.

## What this is NOT

- **Not a parody.** The substance is real or this skill failed. If you cannot make the free atom actually fix the reader's problem, there is no product yet — only a costume. (For a deliberately fictional placeholder product, this is the wrong skill.)
- **Not generic "marketing copy."** It is *one specific genre* with a fixed anatomy (`concept.md`). Bland thought-leadership voice is off-genre; so is dishonest hype. The genre lives in the narrow band between them — see `voice.md`.
- **Not a profile factory.** One profile per product, reused for everything. More products → more profiles; never two profiles for one product — they would drift, and the source of truth must be singular.
